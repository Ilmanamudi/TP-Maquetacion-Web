# SD - Seguridad CCTV & Alarmas

Maquetación web responsive para una landing page orientada a servicios de seguridad electrónica, videovigilancia y alarmas monitoreadas.
Se aplica de manera práctica los conceptos de estructura semántica con HTML5, estilos mediante CSS3 y componentes responsive utilizando el framework Bootstrap 5.

## 📌 Descripción del Proyecto

El proyecto consiste en el diseño y maquetación de una página web optimizada para presentar servicios de instalación de cámaras, alarmas y captación de clientes vía suscripción. 

## 🚀 Características Principales

* **Diseño 100% Responsive:** Adaptación completa a pantallas móviles, tablets y monitores de escritorio utilizando Bootstrap 5.
* **Navegación Intuitiva:** 
  * Menú colapsable tipo "hamburguesa" para celulares.
  * Botones de retorno al inicio en cada sección.
  * Desplazamiento suave (*smooth scroll*) nativo mediante CSS.
* **Estructura Modular:**
  * **Catálogo de Cámaras:** Cuadrícula de productos optimizada para visualización en celulares.
  * **Sección de Alarmas:** Bloque explicativo con distribución dinámica texto e imagen.
  * **Suscripción:** Formulario accesible para suscribirse.
  * **Footer Accesible:** Enlaces a redes sociales con iconos vectoriales SVG. 
* **Accesibilidad & Contraste:** Ajustes en tipografías y contrastes de color para cumplir con estándares WCAG (AA/AAA).

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Semántica limpia y estructurada.
* **CSS3:** Variables nativas (`:root`), gradientes y media queries para vistas en celulares.
* **Bootstrap 5.0.2:** Sistema de layout, grillas responsive y componentes interactivos (Navbar collapse).
